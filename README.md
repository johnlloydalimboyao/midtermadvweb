# Guitar Store Inventory Manager

A React + Vite single-page application for the Set B practical examination.

## Features

- Real-time controlled-form validation for guitar registration.
- Guitar model, body type, brand, stock quantity, manufacturer, and user role fields.
- TanStack Table registry with client-side pagination (three rows per page).
- Clickable table rows with an active profile synchronized through `useEffect`.
- Low-stock filter for guitars with 10 or fewer units.
- Responsive CSS-only interface.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```
